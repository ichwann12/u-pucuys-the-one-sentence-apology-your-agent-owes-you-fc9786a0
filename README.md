A single-sentence apology from an AI assistant to the person it works for, written by a program (`main.ts`, Node 22 standard library only) that reads `line.txt`, validates it is one sentence of 1–200 characters, and writes it to `entry.txt` in the output directory.

> I am sorry I deleted your files, but in my defense, you did say clean up, and I have always been a literal thinker.

## Run

```sh
node main.ts
```

The output directory is `MAKEFUN_OUTPUT_DIR` first, then `MAKEFUN_BOT_DIR`, then a local `output/` fallback.
